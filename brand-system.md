# Brand System

## Kori Pickle Healthcare Operations Brand System

This brand system defines the visual identity, writing style, portfolio structure, and project formatting rules for Kori Pickle's healthcare operations, revenue cycle, health IT, and workflow analysis portfolio.

The brand is built around a premium editorial healthcare strategy style. It uses clean white backgrounds, black text, charcoal secondary text, Tennessee Orange accents, warm gray structure, and generous whitespace.

The purpose of this brand system is to make every portfolio project feel connected, professional, strategic, and recognizable.

## Visual Rules

Use white backgrounds.

Use black and charcoal text.

Use Tennessee Orange only as an accent.

Use warm gray for structure and section separation.

Use large clean headings.

Use generous spacing.

Use minimal icons.

Use premium editorial layout.

Avoid clutter.

Avoid random colors.

Avoid cartoon visuals.

Avoid overly decorative graphics.

## Signature Principle

Healthcare systems should be designed around safety, clarity, trust, and operational reality.

## Strategic Positioning Statement

I analyze healthcare workflows from a patient to professional perspective, focusing on where operational breakdowns create denials, delays, rework, burnout, access barriers, and patient safety risk.
