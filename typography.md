# Typography System

## Typography Direction

The brand uses premium editorial typography with clear healthcare operations readability.

The goal is to look strategic, polished, and professional without becoming decorative or hard to read.

## Headline Style

Use high contrast editorial serif headings when possible.

Headlines should feel confident, clean, and executive.

Recommended headline feel:

Premium

Editorial

Strategic

Sharp

Minimal

Authoritative

## Body Text Style

Use clean modern sans serif body text.

Body copy should be easy to scan and simple to read on desktop and mobile.

Recommended body feel:

Clear

Calm

Professional

Human

Direct

Readable

## Section Labels

Use small caps or uppercase labels with wide letter spacing.

Examples:

STRATEGIC USE CASE

IMPLEMENTATION RISK MAP

EXECUTIVE RECOMMENDATION

WORKFLOW RELIABILITY

## Numbering Style

Use large thin editorial numerals for section numbers.

Examples:

01

02

03

04

## Quote Style

Use large serif quote blocks for signature principles.

Example:

Technology should earn trust before it asks people to depend on it.

## Typography Rules

Keep headings short.

Use strong section hierarchy.

Avoid long dense paragraphs.

Use generous line spacing.

Use sentence case for most body text.

Use uppercase only for small labels.

Do not use too many font styles in one project.

Do not use playful fonts.

Do not use cartoon fonts.

Do not overuse bold text.

## Recommended Pairing

Display or serif font for headings.

Clean sans serif font for body copy.

Simple monospace only for technical documentation or code blocks.
