# Layout Rules

## Layout Identity

The visual layout should feel like premium healthcare strategy, not a generic school project or basic template.

The design should communicate clarity, authority, and operational maturity.

## Core Layout Rules

Use 40 to 50 percent whitespace.

Use clean section blocks.

Use thin Tennessee Orange divider lines.

Use soft warm gray cards.

Use clear section numbers.

Use minimal icons.

Use strong headline hierarchy.

Use structured grids.

Use intentional asymmetry when appropriate.

Keep the page easy to scan.

## Hero Section

Every major project should begin with:

Project name

Short strategic tagline

Created by Kori Pickle

One sentence project purpose

Three to six focus tags

## Recommended Page Order

Hero Section

Strategic Problem

Operational Reality

Risk Map

Workflow Breakdown

Implementation Model

Metrics or Scorecard

Executive Recommendation

Portfolio Positioning Statement

References if needed

Footer

## Card Style

Cards should be simple and structured.

Use warm gray or white backgrounds.

Use thin borders.

Use small orange accents.

Use short headings.

Use readable body text.

Avoid crowded cards.

## Footer Rules

Footer must include:

Created by Kori Pickle

Kori Pickle signature text

Optional LinkedIn and GitHub references

Optional contact email

## Avoid

Crowded layouts

Random icons

Loud gradients

Decorative clutter

Too many colors

Tiny text

Overloaded tables

Unclear section hierarchy

Generic template feel
